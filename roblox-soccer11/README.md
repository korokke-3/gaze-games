# Soccer 11 (Roblox 版・視線なし)

11人制の見下ろし型サッカー。CPU と戦う。
親ディレクトリの視線操作ゲーム (`gazekit/soccer11.py`) から **視線トラッキングを外して**、
Roblox 向けに Luau へ移植し、リーグ戦ゲームとしての要素 (前後半・カード・PK 戦・ショップ等) を足したもの。
Python / Webカメラには一切依存しない。

> 名前・見た目・実在のチームは使っていないオリジナル作品。操作体系は eFootball のスマホ版
> (バーチャルパッド) を参考にしている。eFootball との違いと対応状況は
> [docs/EFOOTBALL_GAP.md](docs/EFOOTBALL_GAP.md) にまとめた。

## 遊び方

| | キー |
|---|---|
| 移動 | `W` `A` `S` `D` |
| パス / スルー / シュート | `K` / `I` / `J` (長押しでパワー) |
| ダッシュ | `Shift` (押しっぱなし。スタミナを消耗する) |
| 技 | `Shift` を軽くタップ → `WASD` を弾く (横: ダブルタッチ / 横→逆: エラシコ / 前→横: シザーズ / 後ろ: ドラッグバック) |
| フリック | ボタンと一緒に矢印キー: `↑↓` フライ・ループ / `←→` インパクト |
| ヘディング・ボレー | 空中のボールの近くで `J` (ゴールへ) / `K` `I` (つなぐ) |
| 守備 | マッチアップ `K` (`↑` でチームプレス) / プレス `I` / タックル `J` / スライディング `L` / 選手交代 `U` (+矢印で方向) |
| その他 | `Q` を2回: ドリブル停止・ショルダーチャージ / `P` 一時停止 / `H` 操作説明の表示切替 / `K` リプレイをスキップ |

スマホ・タブレットでは、左下のスティックで移動、右下のボタンで操作できる
(`ロブ` はトグルで、入れている間 `↑` のフリックと同じ扱い)。

## 試合の流れ

- 前後半 (サイド交代あり)。試合時間は 3 / 5 / 10 分。
- カップ戦モードでは、同点なら延長 2 本 → PK 戦。
- ルール: スローイン、ゴールキック、コーナーキック、オフサイド、ファウル (FK / エリア内は PK)、
  イエロー / レッドカード (2 枚目のイエローで退場)。
- 難易度 5 段階、フォーメーション 4 種、戦術 (守備ラインの高さ・プレスの強さ)。
- ゴール後はリプレイ。試合後はスタッツ (支配率・シュート・パス成功率など) を表示。

## 収益化とコイン

| 項目 | 内容 |
|---|---|
| コイン | 試合の結果で獲得 (勝利 / 得点 / 無失点 / 難易度 / 試合時間)。1 試合の上限あり |
| キット・ボール | コインで解放する着せ替え。**見た目だけで、勝敗には影響しない** |
| VIP (ゲームパス) | コイン 2 倍・VIP 限定のゴールドのキット / ボール |
| 全キット解放 (ゲームパス) | 全キット・全ボール (VIP 限定を除く) |
| コインパック (開発者製品) | 500 / 2,000 / 10,000 コイン |

数値と ID はすべて [`src/shared/Config.luau`](src/shared/Config.luau) (`Rewards` / `Kits` / `Balls` /
`Monetization`)。

### サーバーの信頼境界

試合は 1 人用でクライアントが動かす (入力の遅延を無くすため)。そのため結果の申告は信用せず、サーバー側で次を行う。

- 試合時間・難易度は、開始時にサーバーが記録した値を使う (終了時の申告は使わない)。
- 実時間で規定時間の 80% 未満なら報酬なし。
- 得点・勝敗は範囲に丸め、1 試合の報酬に上限を設ける。
- 購入は `ProcessReceipt` で購入 ID を保存して二重付与を防ぎ、保存に失敗したら再試行させる。
- DataStore はセッションロック付き。取得できない場合はそのセッションを保存しない (巻き戻し事故対策)。

## 開発

```sh
rokit install              # rojo が入る
./check.sh                 # 構文チェック
./tests/run.sh             # 試合ロジック・報酬の検証 (luau CLI が必要)
./tests/smoke.sh           # Roblox API のスタブ上で、クライアント / サーバーを通しで実行
rojo build --output Soccer11.rbxl
rojo serve                 # Studio の Rojo プラグインで Connect → F5
```

Studio でショップを試すには、Game Settings → Security で「Enable Studio Access to API Services」を
オンにする (保存が有効になる)。オフでもメモリ上では動く。

## 元の版からの変更点

- **視線に関わる処理をすべて削除:** ノールックパス、パスコースを読む CPU、視線で変わる技の成否、
  PK でキーパーが視線を読む処理、視線のミニマップ表示。
- **キックオフ直後の保護:** 開始後 1.5 秒は相手がタックルしない (元の版は開始 0.1 秒で奪われた)。
- OpenCV 描画を Roblox のパーツ・GUI に置き換え。色は BGR から RGB に直した。
- 前後半・延長・PK 戦・カード・スタミナ・選手能力・難易度・フォーメーション・戦術・ヘディング・
  GK のダイブ・リプレイ・スタッツ・ショップ・コイン・多言語メニューを追加。
