# Soccer 11 (Roblox 版・視線なし)

11人制の見下ろし型サッカー。CPU と戦う。
親ディレクトリの視線操作ゲーム (`gazekit/soccer11.py`) から **視線トラッキングを外して**、
Roblox 向けに Luau へ移植し、リーグ戦ゲームとしての要素 (前後半・カード・PK 戦・ショップ等) を足したもの。
Python / Webカメラには一切依存しない。

> 名前・見た目・実在のチームは使っていないオリジナル作品。操作体系は eFootball のスマホ版
> (バーチャルパッド) を参考にしている。eFootball との違いと対応状況は
> [docs/EFOOTBALL_GAP.md](docs/EFOOTBALL_GAP.md) にまとめた。

## 遊び方

操作は eFootball (家庭用・スマホ版) の配置に合わせている。対応表と調査の出典は
[docs/EFOOTBALL_GAP.md](docs/EFOOTBALL_GAP.md)。

PC は**マウス中心**。マウスで指した所が狙いになる (指した味方へパス、空いたスペースを指せばそこへ、
シュートはゴールの指した位置へ)。

左手は WASD に置いたまま、右手はマウスから離さずに全部の操作ができるように割り当てている
(操作設定の画面に、指ごとに色分けした図が出る)。

| 指 | キー | 攻撃 | 守備 |
|---|---|---|---|
| 左小指 | Shift | ダッシュ / 押しながら蹴ると強いキック | ダッシュ |
| 左薬指 | A (移動) / Q / Z | Q: 修飾 (ワンツー・ループ) | Q: マウスに近い味方へ切替 / Z: 守備レベル |
| 左中指 | W・S (移動) | | |
| 左人差し指 | D (移動) / E / R / F / G / V / C | E: 浮き球・クロス / R: 修飾 (コントロールシュート・パス&ゴー) / G: 走り込みの指示 / V: 3 人目の予約 / C: 攻撃レベル | E: スライディング / R: 2 人目のプレス / F: マッチアップ |
| 左親指 | Space | スルー | GK 飛び出し |
| 右人差し指 | 左クリック (長押しで強さ) | パス | プレッシャー |
| 右中指 | 右クリック (長押しで強さ) / ホイール | シュート / ズーム | ショルダーチャージ |
| マウスの位置 | — | 狙い (指した味方・スペース・ゴールの隅) | 切替の目標 |

**PC だけの操作 (パッド・スマホには無い):**

- **回転 (スワイプ):** パス・スルー・浮き球・シュートのボタンを離す瞬間 (直前 0.14 秒) にマウスを払うと回転が掛かる。
  狙いは払う前に指していた地点のまま。強く払うほど回転が強い (アナログ)。
  - 横へ払う = 横回転。払った側へ曲がり、曲がる分だけ外へ蹴り出して狙った所を通る (ボールの動きを計算して向きを合わせる)。
  - 前 (狙いの方) へ払う = 順回転。グラウンダーは速く、シュートは低く、浮き球は低く飛んで落ちてからも転がる。
  - 手前へ引く = 逆回転。グラウンダーは浮いて足を越えるチップ、浮き球は高く上がって落ちた所で止まる、シュートは浮く。
  - パッドは溜め中に右スティックで左右のカーブだけ (強さは一定)。
- **走り込みの指示 (G):** マウスで指した地点へ、一番近い味方 (30m 以内) が走り込む。パッドは R3 で前線の味方が裏へ。
- **強さの微調整 (溜め中にホイール):** ゲージをその場で固定し、1 目盛りごとに 5% 増減。タイミングに頼らずパスの強さを合わせられる。
  溜めていない時のホイールは今まで通りズーム。
- **3 人目の予約 (V):** 味方を指して V で「②」を付け、別の味方へパスすると、受けた味方が ② へダイレクトではたく (3 人目の動き)。
  ② をもう一度指して V で取り消し。パッドは L3 (いまの狙いの受け手を予約)。
- **クイック戦術 (1〜4):** 守備ラインを下げる / 上げる、プレスを弱める / 強める。パッドは十字キー左右でプレス。
- 守備の切り替えは Q でマウスに一番近い味方へ (以前から)。
- 操作ヒントを終えた PC の人には、スワイプの回転を 1 回だけ案内する。操作設定の画面にも説明が出る。

- フェイントは **WASD を 2 回押し** (右スティックを弾くのと同じ)。向きは走っている向きに対して決まる。
  ダブルタッチ = 横 / エラシコ = 横 → 反対の横 / シザーズ = 前 → 横 / マルセイユ = 前 → 後ろ → 横 / ドラッグバック = 後ろ。
  例: 右 (D) へドリブル中に W を素早く 2 回 → 上へダブルタッチ。続けて出す技は 0.32 秒以内に次の 2 回押し。
  FK・CK のカーブは溜め中に A / D。操作設定の画面にも「技の出し方」が出る。
- ゲームパッドは eFootball の家庭用と同じ配置 (×=A、□=X、△=Y、○=B、R2=RT、L1=LB、R1=RB、L2=LT、右スティック=フェイント)。

キーボードだけでも遊べる (メニューの「狙い (PC)」をキーボードにすると、WASD の向きが狙い。K = パス、I = スルー、
L = 浮き球、J = シュート)。

**操作設定 (キー割り当ての変更):** メニューの「操作設定」で、全ての操作のキーを変えられる。
キーボード・マウスは 1 操作に 2 つまで (マウスボタンも可)、ゲームパッドは 1 つ。
プリセット (マウス中心 / キーボードのみ) と初期化あり。同じキーを別の操作に割り当てると元の操作から外れる。
チャット (/) や Esc など Roblox が使うキーは割り当てられない。設定はサーバーに保存され、操作ガイドの表記も連動する。

- 向きは狙いで決まり、走る向きとは独立 (後ろの味方にも出せる)。パスアシストは マニュアル / 標準 / フル。
- 受ける前にボタンを入れるとダイレクトで蹴る。空中のボールにはヘディング・ボレー。
- 画面左下の操作ガイドは、攻撃 / 守備 / セットプレー / PK のキーパー と入力機器で中身が変わる。
- スマホ・タブレット: 左のスティックで移動と狙い、右のボタン (攻守でラベルが変わる) を長押しで強さ、右側のスワイプでフェイント。
  画面の大きさに合わせてボタンと表示を縮める。操作ガイドは最初は隠れている (一時停止メニューから出せる)。
- 選手は角ばった人型で、動きは素材を使わず計算で作っている: 走り / パス (インサイド) / スルー / 浮き球・クロス / シュート / ループ /
  ヘディング (ジャンプ) / スローイン / トラップ / 立ったままの奪取 / ショルダーチャージ / スライディング / キーパーのキャッチ・ダイブ / よろけ。
  足技 5 種 (ダブルタッチ・エラシコ・シザーズ・マルセイユルーレット・ドラッグバック) も、技の進み具合に合わせて動く。オンラインでも同期する。
- 画面左上の「II」で一時停止メニュー (再開 / 操作ガイド / 試合をやめる。オンラインは部屋を出る)。
- 初めての試合では、操作ヒント (パス → シュート → ダッシュ → 切替) を順に出す。実際にやると次へ進み、全部やったら二度と出ない。

## モード

- **ソロ**: CPU と対戦 (クイックマッチ / カップ戦)。
- **オンライン協力**: 最大 11 人が同じチームで CPU と対戦。
- **練習**: フリー練習 (相手 0 / 3 / 11 人) と、パス・シュート・足技・FK・守備の 5 ドリル。
  自己ベストを保存する。コインは出ない。一時停止メニューから最初からやり直せる。
- **オンライン対戦**: 最大 11 対 11。部屋を作って、同じサーバーの人が参加する。
- **クイックマッチ (1 対 1)**: 全サーバーの「探している人」から自動で相手を見つける。MemoryStore のキューから 2 人を取り出した
  サーバーが予約サーバーを作り、MessagingService で各サーバーへ知らせ、2 人をそこへテレポートする。着いたら自動で対戦開始。
  45 秒見つからなければ「CPU と対戦」を勧める。相手が予約サーバーに 20 秒来なければ CPU 戦に切り替える。
- **フレンド招待**: 部屋の待機画面から Roblox の招待を送る。招待データにサーバーと部屋の番号を入れ、
  受けた人が別のサーバーに入ったら招待した人のサーバーへテレポートして、同じ部屋に入る。
- **練習のランキング**: 各ドリルの上位 10 人 (全サーバー、OrderedDataStore)。練習はクライアントで動くので記録は申告になる。
  ありえない値 (速すぎるタイム・総数を超える回数) は捨てる。報酬には一切つながらない。
- **ポジション固定**: 1 チーム 4 人以上になると、各自が選んだポジションの選手だけを操作する (切り替え・パス後の移動なし)。
  部屋でポジションを選べる (おまかせなら FW → MF → DF → GK の順に空きへ)。GK も人が操作でき、位置取りは自分、
  セーブ (ダイブ) は自動。人がいない位置と、入力の無い人の選手は CPU が動かす。退場したら固定を外して近い選手を操作する。
  3 人以下は今まで通り、ボールに近い選手へ切り替える eFootball 方式。
  試合はサーバーで動かし、15 回/秒で同期する。

## 試合の流れ

- セットプレーでは全員が配置に着き直す。コーナー・ゴール前の FK は攻撃側がゴール前 (ニア・ファー・PK スポット等) へ入り、
  守備側はマーク・ニアポスト・壁 (ゴールまでの距離で 3〜5 人)。相手は 9.15m (スローインは 2m) 離れ、ゴールキックではエリアの外へ。
  CPU は配置がそろってから蹴る (上限あり)。人間はそろう前に蹴ってもよい (クイックリスタート)。

- 前後半 (サイド交代あり)。試合時間は 3 / 5 / 10 分 (実時間)。時計は 0:00 から 90:00 へ上がり、
  前後半の終わりにアディショナルタイム (得点 1 分・交代 / カード 0.5 分、1〜6 分) が付く。
- 自動交代: スタミナが減った選手を控え (背番号 12〜) と入れ替える。5 人まで・試合中 3 回まで (ハーフタイムは数えない)。
- 守備はミドルブロック: 最終ラインはボール位置に合わせて上下し (ボールが中央なら自陣ゴールから約 40m)、
  チームの縦幅は約 25m。DF と MF は近くの相手をゴール側から 1 人ずつマークする。
- カップ戦モードでは、同点なら延長 2 本 → PK 戦。
- ルール: スローイン、ゴールキック、コーナーキック、オフサイド (スローイン・CK・ゴールキックからは無し)、
  ファウル (FK / エリア内は PK / 相手陣ですぐ拾えるならアドバンテージ)、イエロー / レッドカード (2 枚目のイエローで退場)、
  バックパス (味方が足で出したパスは GK が手で扱えない)、ボール全体がラインを越えたらアウト / ゴール、
  キックオフ時は相手がセンターサークルの外、PK 時はエリアとペナルティアークの外。
- コートは実寸 (105 × 68m、ゴール 7.32 × 2.44m、各エリア・センターサークル・ペナルティアーク・コーナーアーク・フラッグ)。
  選手は身長約 1.8m。ボールだけは見やすさのため実物 (22cm) の約 1.6 倍で描く。
- R1 + シュートはコントロールシュート: ぶれが小さく、ゴールの外側から巻いてファーへ入る。
- 難易度 5 段階、フォーメーション 4 種、戦術 (守備ラインの高さ・プレスの強さ)。
- ゴール後はリプレイ。試合後はスタッツ (支配率・シュート・パス成功率など) を表示。

## 収益化とコイン

| 項目 | 内容 |
|---|---|
| コイン | 試合の結果で獲得 (勝利 / 得点 / 無失点 / 難易度 / 試合時間)。1 試合の上限あり |
| キット・ボール | コインで解放する着せ替え。**見た目だけで、勝敗には影響しない** |
| VIP (ゲームパス) | コイン 2 倍・VIP 限定のゴールドのキット / ボール |
| 全キット解放 (ゲームパス) | 全キット・全ボール (VIP 限定を除く) |
| コインパック (開発者製品) | 500 / 2,000 / 10,000 コイン |

数値と ID はすべて [`src/shared/Config.luau`](src/shared/Config.luau) (`Rewards` / `Kits` / `Balls` /
`Monetization`)。

### サーバーの信頼境界

ソロの試合はクライアントが動かす (入力の遅延を無くすため)。そのため結果の申告は信用せず、サーバー側で次を行う。
オンラインの試合はサーバーが動かすので、報酬もサーバーが結果から直接計算する。

- 試合時間・難易度は、開始時にサーバーが記録した値を使う (終了時の申告は使わない)。
- 実時間で規定時間の 80% 未満なら報酬なし。
- 得点・勝敗は範囲に丸め、1 試合の報酬に上限を設ける。
- 購入は `ProcessReceipt` で購入 ID を保存して二重付与を防ぎ、保存に失敗したら再試行させる。
- DataStore はセッションロック付き。取得できない場合はそのセッションを保存しない (巻き戻し事故対策)。

## 開発

```sh
rokit install              # rojo が入る
./check.sh                 # 構文チェック
./tests/run.sh             # 試合ロジック・報酬の検証 (luau CLI が必要)
./tests/smoke.sh           # Roblox API のスタブ上で、クライアント / サーバーを通しで実行
rojo build --output Soccer11.rbxl
rojo serve                 # Studio の Rojo プラグインで Connect → F5
```

Studio でショップを試すには、Game Settings → Security で「Enable Studio Access to API Services」を
オンにする (保存が有効になる)。オフでもメモリ上では動く。

## 元の版からの変更点

- **視線に関わる処理をすべて削除:** ノールックパス、パスコースを読む CPU、視線で変わる技の成否、
  PK でキーパーが視線を読む処理、視線のミニマップ表示。
- **キックオフ直後の保護:** 開始後 1.5 秒は相手がタックルしない (元の版は開始 0.1 秒で奪われた)。
- OpenCV 描画を Roblox のパーツ・GUI に置き換え。色は BGR から RGB に直した。
- 前後半・延長・PK 戦・カード・スタミナ・選手能力・難易度・フォーメーション・戦術・ヘディング・
  GK のダイブ・リプレイ・スタッツ・ショップ・コイン・多言語メニューを追加。
