# Soccer 11 (Roblox 版・視線なし)

11人制の見下ろし型サッカー。5分間、CPU と戦う。
親ディレクトリの視線操作ゲーム (`gazekit/soccer11.py`) から **視線トラッキングを外して**、
Roblox 向けに Luau へ移植したもの。Python 版・視線機能には一切依存しない。

> 名前・見た目・実在のチームは使っていないオリジナル作品。操作体系は eFootball のスマホ版
> (バーチャルパッド) を参考にしている。

## 状態

- 試合ロジック (`src/shared/Match.luau`) は Studio 無しの自動テスト 40 項目が通っている。
- **Roblox Studio 上での実機確認はまだしていない。** 描画・入力・HUD (`src/client/`) は
  構文チェックと `rojo build` が通るところまで。最初に Studio で F5 を押して確認してほしい。
- 未公開。Universe / Place は未作成。効果音・BGM は未実装 (アセット ID が無いため)。

## 遊び方

| | キー |
|---|---|
| 移動 | `W` `A` `S` `D` |
| パス / スルー / シュート | `K` / `I` / `J` (長押しでパワー) |
| ダッシュ | `Shift` (押しっぱなし) |
| 技 | `Shift` を軽くタップ → `WASD` を弾く (横: ダブルタッチ / 横→逆: エラシコ / 前→横: シザーズ / 後ろ: ドラッグバック) |
| フリック | ボタンと一緒に矢印キー: `↑↓` フライ・ループ / `←→` インパクト |
| 守備 | マッチアップ `K` (`↑` でチームプレス) / プレス `I` / タックル `J` / スライディング `L` / 選手交代 `U` (+矢印で方向) |
| その他 | `Q` を2回: ドリブル停止・ショルダーチャージ / `P` 一時停止 / `H` 操作説明の表示切替 |

ルール: スローイン、ゴールキック、コーナーキック、オフサイド、ファウル (FK / エリア内は PK)、キックオフ。

スマホ・タブレットでは、左下のスティックで移動、右下のボタンで操作できる
(`ロブ` はトグルで、入れている間 `↑` のフリックと同じ扱い)。

## 構成

```
default.project.json     Rojo プロジェクト
rokit.toml               ツール定義 (rojo)
src/shared/Config.luau   数値・陣形・キー割り当て (バランス調整はここだけ)
src/shared/Locale.luau   英語 (正典) / 日本語。LocaleId で自動切替
src/shared/Match.luau    試合シミュレーション。Roblox API 非依存
src/client/              描画 (World) / HUD (Hud) / 入力 (Input) / 起動 (init.client)
tests/                   Studio 無しで動く検証 (luau CLI)
check.sh                 Luau の構文チェック
```

試合はクライアント上で動かす (1 人用で入力遅延を無くすため)。ランキングや課金など
サーバーが要る機能を足す時は、`Match` をそのままサーバーへ移せる (Roblox API に依存していない)。

## 開発

```sh
rokit install              # rojo が入る
./check.sh                 # 構文チェック
./tests/run.sh             # 試合ロジックの検証 (luau CLI が必要)
rojo build --output Soccer11.rbxl
rojo serve                 # Studio の Rojo プラグインで Connect → F5
```

## 元の版からの変更点

- **視線に関わる処理をすべて削除:** 見ている味方への「ノールックパス」、パスコースを読む CPU、
  視線で変わる技の成否 (目線フェイント)、PK でキーパーが視線を読む処理、視線のミニマップ表示。
- **キックオフ直後の保護を追加:** 元の版は、相手が 1.6m 先に居てキックオフ後 0.1 秒で
  ボールを奪われることがあった。開始後 1.5 秒は相手がタックルしない。
- 結果表示の統計を、視線系 (ノールック/読まれたパス) からパス数・カットされた数などに差し替え。
- OpenCV 描画を Roblox のパーツ・GUI に置き換え。色は BGR から RGB に直した。
