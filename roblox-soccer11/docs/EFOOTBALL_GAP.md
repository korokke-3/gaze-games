## 収益化 (eFootball の「コイン」「パック」に相当するものを、フェアな形で)

| 項目 | 内容 |
|---|---|
| コイン | 試合の結果で獲得 (勝利 / 得点 / 無失点)。キットとボールの購入に使う |
| キット / ボール | コインで解放する見た目の着せ替え。**勝敗には影響しない** |
| VIP (ゲームパス) | コイン 2 倍・VIP 限定のゴールドキット / ボール |
| 全キット解放 (ゲームパス) | 全キットとボールを解放 (VIP 限定を除く) |
| コインパック (開発者製品) | 500 / 2,000 / 10,000 コイン |

## 対象外 (別の仕組みが必要)

- **オンライン対戦 (人対人):** 試合をサーバー側で動かして 2 人の入力を同期する作りが必要。
  `Match` は Roblox API 非依存なので移行は可能だが、別途設計が要る。
- **実況・歓声・BGM:** 利用できる音源 ID が無い。

## 実装後の検証

- 試合ロジックは自動テストで確認済み (前後半・サイド交代・スタミナ・カード・退場・
  フォーメーション・難易度・PK 戦の勝敗判定・リプレイ・ヘディング・GK ダイブ・スタッツ・報酬)。
- CPU 同士を 5 分 × 16 試合回した平均: 得点 1.7 / シュート 11 / 枠内 79% / セーブ 4.4 / コーナー 0.9 /
  ファウル 0.6 (人間がスライディングを使うとファウル・カードが増える)。実際の試合より少なめ。
- 描画・HUD・メニュー・ショップ・購入フローは Studio / 実機での確認が必要。
