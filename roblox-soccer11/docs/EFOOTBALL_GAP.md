## 前回までの問題 (ご指摘) と対応

| ご指摘 | 原因 | 対応 |
|---|---|---|
| 進む方向にしかパスを出せない | パスの向きを「移動の向き」から決めていた | 向きは**狙い** (マウス / 左スティック / タッチのスティック) で決め、走る向きとは独立させた。後ろ・横の味方にも出せる |
| 8 方向しか選べない | WASD の 8 方向だけだった | **マウスで 360° 狙える**。ゲームパッド・タッチはアナログ (移動の速さも倒し具合で変わる) |
| パスの強さを調節できない | 強さを自動で決めていた | **長押しでパワーゲージ**、離して蹴る (パス・スルー・浮き球・シュート・FK・CK)。パスアシスト「マニュアル / 標準 / フル」で、ゲージが距離に効く割合を選べる |
| ボット (味方 AI) がボールを取りに来ない | ① パス後に受け手へ操作が移り、入力が無いと受け手が止まっていた ② 受け手が決まると他の味方がこぼれ球を追わなかった ③ 操作中の選手が一番近いと、AI が寄せに行かなかった | ① 入力の無い操作中の選手は AI が補助 (受けに行く・寄せる) ② 受け手が届かない時は、届く別の味方が追う ③ 寄せ役は操作中でない選手から必ず選ぶ |
| 操作が分かりにくい | 固定の説明文だけだった | **状況 (攻撃 / 守備 / セットプレー / PK のキーパー) と入力機器 (キーボード / パッド / タッチ) で変わる操作ガイド**。狙いの矢印 (溜めると伸びる)、パスの受け手の輪、パワーゲージ、タッチボタンの表示も攻守で切り替え |
| 協力・対戦が無い | 1 人用だけ | **オンラインの協力 (最大 3 人 vs CPU) と対戦 (最大 3 対 3)**。試合はサーバーで動かし、15 回/秒で同期 |

## 操作の対応表 (eFootball → この版)

## 「全く同じ」にできないもの

| 項目 | 理由 |
|---|---|
| 実在のチーム・選手・リーグ・ロゴ・名前 | 権利。オリジナルのチームのまま |
| 3D の選手モデル・モーションキャプチャ・実況 | 素材が無い (Roblox で作り直すには別途の制作が必要)。見下ろし型の 2.5D 表示 |
| 選手のガチャ (Dream Team の選手獲得・育成) | 実在選手を使わないため、同じ仕組みは作っていない。キット・ボールの着せ替えで代替 |
| サーバーをまたぐマッチング (ランク戦) | 今は「同じサーバー内の部屋」で協力・対戦する。別サーバーの人とのマッチングは MemoryStore と予約サーバーへのテレポートが必要で、未実装 |
| 協力でのリーダー権限 | 協力では誰でも攻守レベルを変えられる (eFootball はリーダーのみ) |
| オンラインの遅延補償 | 補間 (0.1 秒遅れ) のみ。自分の操作の先読み (クライアント予測) はしていないので、通信が遅いと操作が遅れて見える |

## 検証

- 試合ロジック: 自動テスト 124 項目 (どの方向にもパスを出せる・アナログの狙い・長押しの強さ・ボールの回収・協力・対戦・同期の圧縮形式など)。
- クライアント / サーバー: Roblox API のスタブ上で通し実行 (ソロ・協力・対戦・部屋・入力の往復・報酬)。
- CPU 同士 5 分 × 12 試合の平均: 得点 1.5 / シュート 12 / 枠内 86% / セーブ 5.0 / コーナー 0.8 / こぼれ球の最長 2.0 秒。
- **Roblox Studio・実機・複数人での確認は未実施** (見た目・操作感・通信の遅れ)。
